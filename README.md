# Bulwark — playtest builds

Bulwark is a colony-defence game in development: build a colony, wall it in, and survive waves of tens of thousands
of infected until the last day.

**Download:** see [Releases](../../releases) and grab the latest `Bulwark-playtest-*.zip`.

1. Unzip anywhere and run `Bulwark.exe` (Windows 10/11, 64-bit; nothing to install).
2. If Windows SmartScreen warns about an unknown app: "More info" → "Run anyway" (the build isn't code-signed).
3. The `README.md` inside the zip has the controls and what feedback helps most.

This repository only hosts playtest downloads; it contains no source code.
